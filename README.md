# Sistema de Gestión Integral para Consignatarios de Haciendas (SGCH)

Este repositorio contiene el prototipo operacional del sistema SGCH, desarrollado para la materia **Seminario de Práctica de Informática** (Universidad Siglo 21).

## Tecnologías Utilizadas
* **Lenguaje:** Java 17
* **Framework:** Spring Boot 3.5
* **Persistencia:** Spring Data JPA / Hibernate
* **Base de Datos:** MySQL 8.0
* **Vistas:** HTML5 / Thymeleaf

## Estructura del Repositorio
* `/src/main/java/.../model`: Clases de dominio aplicando herencia, encapsulamiento y polimorfismo.
* `/src/main/java/.../service`: Lógica de negocio y reglas transaccionales (RN02).
* `/sgch_db.sql`: Script DDL y DML para la creación de la base de datos relacional.
